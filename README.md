# CYBERNEX V14 — THREE WORLDS
مشروع بدر: الأمن السيبراني × Python × هندسة البرمجيات.

## تشغيل النسخة
- ارفع محتويات هذا المجلد كاملة إلى مشروع Vercel الحالي، بما فيها assets وvendor.
- Framework Preset: Other. بدون أمر Build. اجعل مجلد الإخراج هو المجلد الذي يحتوي index.html.
- لا ترفع index.html وحده؛ الصور والبرمجة وملفات التنسيق ضرورية.
- على الهاتف افتح رابط الموقع بعد النشر. فتح index.html من تطبيق الملفات قد يمنع JavaScript modules؛ استخدم استضافة أو خادم محلي.
- رابط Vercel الحالي لم يتم تعديله تلقائياً من هذه الجلسة.

## الإضافات
- رئيسية حقيقية لا تختفي تلقائياً، وثلاثة اختيارات مستقلة للعوالم.
- دخول خاص لكل عالم: فتح القفل، تجميع رموز البرمجة، تجميع وحدات التطبيق.
- GSAP وScrollTrigger محليان: page load + scroll، popup، fade + scale، stagger + dropdown.
- صورة رئيسية مولدة للمشروع، ورسومات محلية لكل عالم. لا تعتمد الصور على خدمات خارجية.
- إعدادات محفوظة: قوة الحركة، الخلفية، سرعة الانتقال، شدة الإضاءة، دخول العوالم، التنبيهات، نص التقديم، حجم الخط، التركيز، السطوع، وألوان الهوية.
- 4 أوضاع جاهزة: سينمائي، متوازن، خفيف للهاتف، شاشة الصف.
- 12 سؤالاً إضافياً مع تفسير ونتيجة وأفضل نتيجة محلية، وأسئلة متوقعة من المعلم.
- الحفاظ على الدروس الأربعة للأمن، والخمسة لبايثون، والخمسة للهندسة، والمختبرات والألعاب والعرض السابق.
- حقوق بدر واضحة في الرئيسية والتذييل.

## توزيع الحركة
- الرئيسية: دخول متدرج للعناوين + تكبير هادئ للصورة.
- بطاقات العوالم والقائمة: stagger/drop down.
- الدروس: fade in/scale عند التمرير.
- انتقال العوالم: شاشة قصيرة يمكن تجاوزها، مع تنبيه غير حاجب.
- مشاهد التمرير: القفل، الكود، تجميع التطبيق.
- الخلفية: إضاءة وجسيمات خفيفة، مع توقف الجسيمات عند إخفاء التبويب.

## حدود التجارب
محرر Python محاكاة تعليمية محدودة للطباعة والمتغيرات، وليس مفسراً كاملاً. غرفة العمليات وأداة تصميم التطبيق محاكاة محلية وليستا اتصالاً بأجهزة أو خدمة نشر.
Three.js يستخدم WebGL عند توفره. إذا لم يتوفر WebGL تبقى الصور ومشاهد CSS والتفاعلات متاحة. متصفح الاختبار لا يوفر WebGL لذلك لم يمكن التحقق بصرياً من المشهد الحقيقي ثلاثي الأبعاد فيه.
الإعدادات والنتائج محفوظة في localStorage على المتصفح نفسه فقط. خط Cairo وSpace Grotesk يُحمّلان من Google Fonts مع خطوط بديلة عند انقطاع الإنترنت.
